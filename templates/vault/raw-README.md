# raw/ — sources

Drop anything here you want EVIE to learn from: class handouts, articles (saved as PDF or text),
meeting notes, client briefs, screenshots (in `assets/`), spreadsheets.

- **EVIE reads these and never edits them.** If a file is wrong, add a corrected file next to it.
- **Name files** `YYYY-MM-DD-short-name.ext` (the day you added it).
- Then say **"ingest raw/<file>"**. EVIE reads all of it, tells you the takeaways, writes the
  summary page, updates related pages and the index, and logs it. One file at a time.
- The vault checker lists any file here that no page cites yet, so nothing sits forgotten.
